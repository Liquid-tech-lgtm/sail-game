# 🏴‍☠️ Salt & Sovereigns — Open Waters

**Salt & Sovereigns — Open Waters** is a top-down pirate trading game built around sailing, trading, exploration, contracts, naval encounters, ship upgrades, and building your fortune across the open waters.

This repository is primarily an **archive of older playable versions of the game**. Each version represents a different point in the game's development, allowing players to go back and experience how the game changed over time.

## 🌊 What Is the Game?

You take control of a ship and travel between ports across the open waters.

Your goal is simple:

**Sail → Trade → Earn → Upgrade → Explore → Become Wealthy**

But the journey isn't completely safe.

You have to manage your ship, avoid dangerous reefs, deal with the Navy, make profitable trading decisions, complete contracts, and decide how you want to build your fortune.

## ⚓ Core Gameplay

### 🛳️ Sailing

Control your ship using:

* **WASD**
* **Arrow Keys**

Your ship has momentum, so turning and braking require planning rather than instant movement.

### 💰 Trading

Visit different port islands and buy commodities where they're cheap.

Then sail somewhere else and sell them where demand is higher.

Prices can change when time advances in port, making planning your trading routes an important part of the game.

### 📜 Contracts

Later versions introduce legal contracts such as:

* Cargo deliveries
* Passenger runs
* Supply orders
* Courier dispatches

Contracts have destinations, deadlines, and fixed payouts, giving players another way to earn money besides traditional trading.

### ⚔️ Naval Encounters

The game also features Navy encounters.

Players can encounter different danger levels, choose whether to fight, and potentially earn gold and salvage from successful encounters. Losing can cost cargo and gold while damaging the ship.

### 🪨 Reefs

Reefs are dangerous obstacles throughout the world.

Colliding with them damages the ship, so navigation matters while travelling between ports.

Later versions also improved how the Navy handles reefs, allowing Navy cutters to navigate around them instead of simply sailing straight through.

## 🏆 Progression

Money becomes more than just a trading number as the game develops.

Players can build their wealth through:

* Trading
* Contracts
* Combat
* Smuggling
* Ship upgrades
* Other economic systems

Later builds track **Lifetime Earnings** separately from current Gold, while Net Worth can include gold, cargo, ship value, and upgrades.

## 🗺️ Maps & Navigation

The game includes a minimap and larger chart systems for navigating the world.

The **M key** opens the larger Map / Market / Ports interface in later versions.

## 📖 Captain's Manual

Later versions include an in-game Captain's Manual organized into sections such as:

* Getting Started
* Trading
* Ships
* Navigation
* Combat & Navy
* Economy
* Controls
* Tips

The goal was to make the game easier to understand without forcing players to read through one huge help page.

## 👁️ Hide HUD

Later versions also include a **Hide HUD** feature.

Press **H** to hide the title bar and Ship's Dashboard while keeping important gameplay elements such as the minimap and M-key charts available.

## 🎮 Controls

| Key           | Action              |
| ------------- | ------------------- |
| **W / ↑**     | Accelerate          |
| **S / ↓**     | Brake / Reverse     |
| **A / ←**     | Turn Left           |
| **D / →**     | Turn Right          |
| **E / Space** | Dock when prompted  |
| **M**         | Open / Close Charts |
| **Esc**       | Pause / Close Menu  |
| **H**         | Hide / Show HUD     |

Controls and HUD behavior are documented in the later Captain's Manual.
